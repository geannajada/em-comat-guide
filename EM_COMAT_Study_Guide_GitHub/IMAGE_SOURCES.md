# Version 11 image sources

**35 new extracted textbook figures**, plus the two previously included licensed images.

Each figure was visually checked against the source page and caption. Crops preserve source labels/arrows and original image content. Images were rendered from the supplied PDFs, cropped to the figure, and saved as PNG; no AI-generated reconstruction, diagnostic retouching or contrast enhancement was applied. Some originals are low-resolution, so enlargement cannot reveal detail absent from the source.

The user confirmed permission to publish the textbook images. That confirmation is not an independent rights audit. Existing third-party credits are recorded below; inclusion does not imply a new open license.

Moderate confidence: figure identity and descriptive clues are supported by the textbook figure/caption. The next-step comments connect the image to the existing v10 clinical reference; a still image is not a substitute for clinical context or a complete imaging examination. Selection priority is editorial inference, not measured exam frequency.

## Coverage and use

The new figures appear in Cardiovascular, Respiratory, Shock, Trauma, GU/Renal, MSK, GI, HEENT, Skin and Neuro. The overview has direct gallery buttons. Each gallery is expandable, searchable, keyboard accessible, and uses stacked image/text on narrow screens. Select a figure to open its larger PNG.

No new figure was added merely to fill a tab. Endocrine, toxicology, public health and other tabs retain their existing clinical material; related potassium and urine-crystal images appear in GU/Renal.
